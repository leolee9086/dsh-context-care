## 保留行为

- 通知来源等待期间控制变化会丢弃提案，且不花掉去重或冷却。
- 完成观察仅检查已提交的可见 text，先检查字符预算再拼接，不把 reasoning、引用、失败 attempt 当作完成。
- 完成回执丢失会消耗有限重试额度；缓存清空和独立 Host 重放仍能恢复，分支不继承父会话本地提醒或冷却。
- 完成候选只保存 provider/model 路由身份，不扩散请求配置字段；旧持久身份与 schema 保持兼容。
- 流式 line-repeat 仍按原动作顺序取消后续接，自动续接保留原上限；真人输入只重备提醒，不重置原有 abort 生命周期。
- 请求改写审计失败或控制版本变化不提交 once-per-body、冷却或前缀基线。
- 循环清理只动最后一条助手消息的严重命中，保持历史原文、未改变块身份和重复执行的稳定结果。
- 引擎严格 TypeScript/ESLint 配置未放宽，保留原 v1 引擎行为。
