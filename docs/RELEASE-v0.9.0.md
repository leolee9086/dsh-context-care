# v0.9.0 — 共享规则提醒

新增跨插件共享的 `reminderRules` 服务，接收外部提醒来源、判定器和输入分析器，通过独立 Worker 完成规则执行，并在会话请求中收集有效提醒。

- 来源快照校验、候选持久化、去重、冷却和来源变更使用统一运行时；提交状态等待存储 ACK。
- 规则侧栏增加提醒来源和容量状态，提供容量配置与拒绝原因；沿用会话的规则与动作开关。
- 修复取消、失败和超时后的 Worker 释放与替补，让后续任务继续获得执行容量。
- 思源 callout 来源由思源插件维护内部订阅、屏障及固定查询，模型工具仍按原有端点政策授权。
- GitHub 标签与发行归档携带完整运行源码和已构建客户端。

安装引用：`github:leolee9086/dsh-context-care#v0.9.0`。思源提醒来源使用 `github:leolee9086/dsh-plugin-siyuan#v0.4.0`。

验证：99 个源文件语法检查通过，277/277 项测试通过，客户端构建通过。跨插件真实思源 callout 样本经来源读取、独立 Worker 到提醒收集，首次得到 1 条，重复收集为 0 条。运行中插件由安装方加载。
